## What changed today, and why each one matters

Eleven merges. The through-line is one defect shape, stated eleven ways: **a
mechanism that stopped working while every surface still read green.**

- **The GDELT work ledger was inert for its entire life** (#232). It was
  supposed to retry abandoned query windows across runs. It wrote to a file on
  Railway, whose container is ephemeral, so the committed ledger held zero
  slots while production abandoned 7 of 12 windows a run. Nothing reported it
  because the health page said `degraded`, which reads as "known gap, queued".
  Now round-trips through the keyed `/tracker-meta` endpoint.
- **That fix was itself inert in the runs that needed it** (#233). It saved at
  END of run, and this job measurably dies mid-run — `railway-cron` wrote no
  end-of-run record on 08-16, 08-19 or 08-26. Now syncs during the run,
  throttled to one push per two minutes.
- **GDELT refuses with HTTP 200 and a sentence** (#238). "Your query was too
  short or too long" is a load-shed message wearing a validation message's
  words — the identical query was refused then accepted minutes apart. So
  `raise_for_status()` passed, `resp.json()` threw, and all three places built
  to tell throttled from broken got the wrong answer. An upstream throttle was
  raising a RED run, which is exactly what that code's comment says it prevents.
- **A timeout the operator set did nothing** (#239). `timeout=30` was a
  hardcoded literal. He set a Railway variable for it and no code read it. Now
  `GDELT_QUERY_TIMEOUT`, clamped 5..90, default unchanged.
- **That fix broke a test in another file** (#240). Its test called
  `importlib.reload(gdelt)`, rebuilding `_THROTTLE_BODY_RX`, which
  `gdelt_backfill` imports BY REFERENCE — so an identity assertion elsewhere
  failed with "two identical regexes are not each other". A test that reloads a
  module others hold references into does not fail where it is written.
- **Seven anonymous employers were published** (#241). `Unknown` — the
  extractor's own null sentinel — appeared as an employer three times, plus
  `Automaker Giant` (50,000 jobs, no country, the largest "verified" event on
  the tracker), `Auto-parts giant`, `DTC storage firm`, `Social media giant`.
  Nothing ever asked whether `company` named a company. Gate added at
  `alt_db_upsert`; the seven rows were trashed on 2026-08-29 with owner
  sign-off and their dedup hashes suppressed.
- **Country identities were split live**: China 17,790 / PRC 2, South Korea

## Rules that cost something to learn

- **Never widen a threshold, a timeout or a caveat to quiet an alarm.** If the
  honest answer is UNKNOWN, say UNKNOWN. `self_heal.py` has a FORBIDDEN list
  for exactly this: a healer may fix a collector but never the judge.
- **Prove a fix by MUTATION.** Revert it, watch the specific test fail, report
  which. Every change today did this. It caught two real errors — a blocklist
  that would have silently deleted **Public Storage**, and my own test
  reloading a module other modules hold by reference.
- **A deletion is the operator's.** Normalising and correcting are not.
- **Check `git show --stat` after committing.** Sessions share this working
  tree; `git add -A` swept in another session's files today.
