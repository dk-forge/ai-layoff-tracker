## Method and honest limits
- List built from web search on 2026-11-08, mostly secondary trackers. Items marked
  (S) rest on an aggregator count I did not trace to the company's own filing; the
  rest were confirmed in at least one major outlet, an SEC 8-K, or a state WARN notice.
- Excluded on purpose: Microsoft (voluntary exit offers to ~60,000, not layoffs),
  Disney and Virgin Media O2 ("thousands", no count), Canva (22% of staff, no count),
  Omnicom (15,000, one tracker only, unconfirmed), HubSpot/Hasbro/Royal Mail (before 10-09).
- **Time to first listing is NOT measurable this week.** The API exposes no first-seen
  timestamp, only `announcement_date` and `layoff_date`. Where those equal the event
  date, latency is at most the page's own freshness; the one provable lateness is NAB.
  Action: snapshot the id range each Sunday so next week's latency is real.

## Misses by cause (11)
- **No row: 9.** Dutch government, Amex, Fiserv, Ecco, GSK, NatWest, Weil Gotshal,
  Innodata, Swedbank. Four are large US-listed or major-outlet stories (Amex, Fiserv,
  Dutch gov, Ecco), so this is a discovery gap, not an obscure-source gap.
- **Wrong count: 2.** Flutter (8-K says 1,400, rows hold two partial Eurofound
  figures), KLM (reorganised jobs read as cut jobs).
- **Late: 1 counted as a hit.** NAB, 15 days.

## Precision findings (not in the 25, found while scoring)
Four live rows at the top of the window are not new layoffs of that size:
- Nokia 4,000 (id 183047, 11-05): a San Diego profile recalling the **2011** layoffs.
- Bosch 30,000 (id 183019, 11-05): FAZ headline "steigt auf mehr als 30.000", a running total.
- Wells Fargo 10,000 (id 183096, 11-06): headcount shrinkage to date, not one event.
- KLM 5,000 (id 182986): see row 16.
These inflate the headline numbers more than any miss deflates them.

## Fix shipped (top cause that is fixable in one small PR)
Retrospective guard (`extractor.retrospective_verdict`) now treats "in <year up to
2024>" and "rises/climbs to ... / steigt auf ..." as retrospective, so the Nokia and
Bosch shapes are no longer stored as new events. Tests first
(`tests/test_extractor_retrospective.py`, +4, red before, green after). Railway-only,
no plugin deploy, no spend. Existing rows 183047 and 183019 were NOT edited; they need
a reviewed correction (owner or adjudication flow), see "Next".
